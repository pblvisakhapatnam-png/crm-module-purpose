# Slice 0F - Document Metadata Foundation

## Goal

Activate the document metadata foundation before Account/business_party implementation begins.

## Scope

Includes:

- document metadata API routes;
- document type lookup route;
- recent document metadata route;
- document metadata create route;
- by-record document metadata route;
- business event creation when document metadata is linked;
- frontend Documents smoke page;
- backend tests.

## Out of scope

- binary file upload;
- SharePoint integration;
- OCR;
- AI document extraction;
- document verification workflow;
- document locking;
- Account-specific document tabs.
